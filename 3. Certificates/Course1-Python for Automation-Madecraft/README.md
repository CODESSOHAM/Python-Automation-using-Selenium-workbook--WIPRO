\# Course 1: Python for Automation

## Certificate Overview

This folder contains the certificate earned for **Python for Automation**, a Madecraft course completed through Coursera.

The course introduces the use of Python to automate repetitive tasks and build practical automation scripts. It provides a foundation for applying Python in automation workflows, including writing readable scripts, working with programming logic, and using automation to improve efficiency and consistency.

## Course Details

- **Course:** Python for Automation
- **Provider:** Madecraft
- **Platform:** Coursera
- **Certificate:** `C1-Python for Automation - MADECRAFT.pdf`
- **Course focus:** Python programming fundamentals and practical automation concepts

## Key Learning Areas

The course supports learning in the following areas:

- Understanding how Python can be used for automation
- Writing Python scripts for repetitive tasks
- Applying variables, data types, conditions, and loops
- Organizing logic into reusable functions
- Building a foundation for Python-based test and web automation
