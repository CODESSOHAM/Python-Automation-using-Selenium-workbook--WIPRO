# Course 3: Test Automation with Playwright (Python) & Robot Framework

## Certificate Overview

This folder contains the certificate earned for **Test Automation with Playwright (Python) & Robot Framework** through Coursera.

The course focuses on modern web application test automation using Playwright with Python and the Robot Framework. It introduces practical approaches for creating reliable, readable, and maintainable automated tests.

## Course Details

- **Course:** Test Automation with Playwright (Python) & Robot Framework
- **Platform:** Coursera
- **Certificate:** `C3-Test Automation with Playwright (Python) & Robot-Coursera.pdf`
- **Course focus:** Playwright, Python, Robot Framework, and web application test automation

## Key Learning Areas

The course supports learning in the following areas:

- Setting up Playwright with Python
- Automating browser interactions with Playwright
- Locating and interacting with web page elements
- Creating automated tests for web applications
- Understanding test organization and maintainability
- Using Robot Framework for keyword-driven automation
- Combining Python-based automation skills with structured testing practices
