\# Course 2: Selenium WebDriver with Python

## Certificate Overview

This folder contains the certificate earned for **Selenium WebDriver with Python**, a Whizlabs course completed through Coursera.

The course focuses on using Python with Selenium WebDriver to automate web browsers and validate web application behavior. It introduces the core techniques needed to create, execute, and maintain browser automation tests.

## Course Details

- **Course:** Selenium WebDriver with Python
- **Provider:** Whizlabs
- **Platform:** Coursera
- **Certificate:** `C2-Selenium WebDriver with Python-Whizlab.pdf`
- **Course focus:** Selenium WebDriver, Python, and browser-based test automation

## Key Learning Areas

The course supports learning in the following areas:

- Setting up Selenium WebDriver with Python
- Launching browsers and navigating web pages
- Locating elements with Selenium locators
- Interacting with forms, buttons, links, dropdowns, and checkboxes
- Working with waits and dynamic web elements
- Organizing and maintaining browser automation tests
