## 5. Full Capstone Project

### API Automation Framework Using Python, Requests, Behave BDD, and Allure

The capstone brings the workbook's automation principles together in a reusable REST API testing framework. It keeps business-readable behavior separate from request implementation and validation details.

**APIs covered:**

- **JSONPlaceholder:** user-management CRUD operations, including retrieval, creation, update, deletion, and not-found behavior.
- **Automation Exercise API:** products, brands, product search, and login verification with valid, invalid, missing-data, and unsupported-method scenarios.

**Framework layers:**

| Layer | Responsibility |
|:--|:--|
| Feature layer | Describes expected behavior in Gherkin scenarios, tags, backgrounds, and scenario outlines |
| Step layer | Connects readable steps to Python actions while keeping scenarios clear |
| Client layer | Centralizes requests, sessions, headers, timeouts, and endpoint-aware operations |
| Configuration layer | Stores URLs and settings with environment-variable overrides |
| Validation layer | Checks HTTP status codes, API response codes, fields, messages, and JSON structure |
| Evidence layer | Logs execution details and attaches request/response data to Allure |
| Offline check | Uses mocked HTTP calls to verify core framework behavior without network access |

**Important implementation detail:** JSONPlaceholder uses normal HTTP status codes. Automation Exercise commonly returns HTTP `200` at the transport level and places the meaningful result in the JSON `responseCode` field. The framework validates each API according to its actual behavior.

## 10. Recommended Learning Path

1. Begin with the setup and configuration videos.
2. Complete M1 to establish Selenium browser-automation fundamentals.
3. Review the screenshots and assignment README files after each exercise.
4. Continue with M2 to learn test organization, `pytest`, `unittest`, and POM.
5. Study M3 to connect automation behavior with BDD and REST concepts.
6. Explore M4 to understand keyword-driven automation and reusable Robot Framework keywords.
7. Read the capstone project description before opening its framework code.
8. Run the offline smoke test first, then execute selected Behave features and generate Allure results.
9. Finish with the capstone videos and supporting certificates for a complete learning record.
