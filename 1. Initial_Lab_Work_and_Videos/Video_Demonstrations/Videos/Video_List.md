# Selenium Automation Video Demonstrations

This list contains video demonstrations covering Selenium installation, configuration, beginner automation, and the initial Module 1 assignments.

## Video List

### 1. Initial Selenium Setup, Installation, and Configuration

This video demonstrates how to prepare the environment for Selenium automation. It covers the initial installation steps, required configuration, and setup needed to run Python-based Selenium scripts.

> **[WATCH VIDEO: Setup, Installation, and Configuration](https://drive.google.com/file/d/1PEkRAM8PldHklL7ypO0YY5GfTpsOBYyB/view?usp=sharing)**

### 2. Running a Beginner-Friendly Test Script

This video demonstrates how to run a simple Selenium test script. It introduces the basic flow of opening a browser, navigating to a webpage, interacting with elements, and observing the test result.

> **[WATCH VIDEO: Beginner-Friendly Test Script](https://drive.google.com/file/d/108corUJE8yRjgeSnI5C32w5kxHbpmNB8/view?usp=sharing)**

### 3. Module 1 Assignment 1: Web Element Identification

This assignment demonstrates how to identify and locate different web elements using Selenium locator strategies, including:

- `By.ID`
- `By.NAME`
- `By.TAG_NAME`
- `By.LINK_TEXT`
- `By.CLASS_NAME`

For example, the script locates a username field by ID, a password field by name, and a link by its link text.

> **[WATCH VIDEO: Assignment 1 - Web Element Identification](https://drive.google.com/file/d/1r9RoSsJRqIr2FG8JUUSdf1Igg2IHrGm-/view?usp=sharing)**

### 4. Module 1 Assignment 2: Multiple Element Identification

This assignment demonstrates how to identify multiple elements of the same type using Selenium. It finds all links on a webpage, stores the matching elements in a list, and prints the text of each link.

> **[WATCH VIDEO: Assignment 2 - Multiple Element Identification](https://drive.google.com/file/d/11_x1zU8eXRw7UbXSlgRzQnSzsRZhc2Bv/view?usp=sharing)**

### 5. Module 1 Assignment 3: CSS Selector Challenge

This assignment demonstrates how to locate web elements using CSS selectors, including wildcard selectors for elements with varying or dynamic attribute values. For example, a CSS wildcard selector can locate elements whose IDs start with `user_`.

> **[WATCH VIDEO: Assignment 3 - CSS Selector Challenge](https://drive.google.com/file/d/1BOhdXphrNO9JkaTiBqg7UHXkU3rgxmHT/view?usp=sharing)**

### 6. Module 1 Assignment 4: Child Nodes Using CSS

This assignment demonstrates how to identify and locate child or nested web elements using CSS child selectors. For example, the script locates and interacts with a button inside a specific `div` element.

> **[WATCH VIDEO: Assignment 4 - Child Nodes Using CSS](https://drive.google.com/file/d/11JY8tWgKx1lG_bvCpJfRbZkeyeW8_mNF/view?usp=sharing)**
