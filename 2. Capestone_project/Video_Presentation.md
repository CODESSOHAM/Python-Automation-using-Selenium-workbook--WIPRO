# Capstone Project Video Demonstration

## Overview

The demonstration of this API Automation Framework is divided into two videos. Together, they explain the project design and show the framework running in practice.

## Video Demonstrations

### 1. Theoretical Explanation

This video provides a theoretical overview of the capstone project. It explains the project objective, framework architecture, tools and technologies, API coverage, BDD approach, folder structure, test methodology, reporting process, and the main concepts used in the implementation.

> **VIDEO 1 | THEORY**  
> Project architecture, concepts, methodology, and framework design  
> ### [OPEN VIDEO 1: THEORETICAL EXPLANATION](https://drive.google.com/file/d/17pWIa_2yLliFVUSxDfTc95OsFwa_yTds/view?usp=sharing)

### 2. Live Execution Demonstration

This video provides a live execution demonstration of the project. It shows the setup or execution of the API automation tests, the Behave scenarios being run, response validations, test results, and the generated reporting workflow.

> **VIDEO 2 | LIVE EXECUTION**  
> Test execution, API responses, validations, results, and reporting  
> ### [OPEN VIDEO 2: LIVE EXECUTION DEMONSTRATION](https://drive.google.com/file/d/1XLYuZAC7vvgmXDYRQ_XQd_Nyeu7YSwfx/view?usp=drive_link)

## Recommended Viewing Order

1. Watch the **Theoretical Explanation** to understand the project structure and testing approach.
2. Watch the **Live Execution Demonstration** to see the framework and test scenarios in action.

Viewing both videos provides a complete understanding of the project, from its design and methodology to its practical execution and results.
